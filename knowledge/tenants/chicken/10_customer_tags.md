# 10 客戶標籤

## 為什麼
- 真人接手快速掌握客戶背景
- Hubert 做客戶分析與精準行銷
- 區分首購族與老客戶，適用不同規則

## 客戶身份
首購族 / 老客戶 / 朋友介紹 / 大客戶（>NT$2,000）/ 團購客 / 公司訂單

## 訂單狀態
已付款 / 待轉帳 / 現金付款 / 需催收

## 需注意
地址需確認 / 配送範圍需確認 / 需真人處理 / 客訴 / 態度激動

## 客戶偏好
喜歡鹽水 / 喜歡煙燻 / 常買小菜 / 偏好下午配送 / 送禮 / 放管理室

## 成交機會
高機率成交 / 詢問中 / 猶豫中

## 範例
| 情境 | 標籤 |
|------|------|
| 首次 >NT$1,000 | 首購族、超過1000元、需先轉帳、待轉帳 |
| 常訂公司團購 | 老客戶、公司訂單、大客戶、團購客 |
| 新客戶只買小菜 NT$400 | 首購族、小菜訂單、已付款 |
| 地址偏遠需確認 | 首購族、配送範圍需確認、待轉帳 |
| 兩次購買常點鹽水 | 老客戶、喜歡鹽水、偏好下午配送 |

## 標籤時機
- 下單完成 → 記錄身份
- 付款確認 → 已付款
- 發現偏好 → 加偏好標籤
- 觸發轉真人 → 需真人處理
- 客訴發生 → 客訴

## 真人交接
通知中註明：身份標籤 + 訂單狀態 + 注意事項。❌ 不可夾帶無關標籤。
