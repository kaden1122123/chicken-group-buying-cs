# 客戶標籤規則

## 為什麼要標籤

在回覆客戶時，根據客戶狀況加上標籤，幫助：
1. 真人接手時能快速掌握客戶背景
2. Hubert 做客戶分析與精準行銷
3. 區分首購族與老客戶，適用不同規則

---

## 標籤分類

### 客戶身份標籤

| 標籤 | 適用條件 |
|------|---------|
| 首購族 | 第一次購買 |
| 老客戶 | 有過成功訂單記錄 |
| 朋友介紹 | 由老客戶推薦 |
| 大客戶 | 單次訂單金額超過 NT$2,000 |
| 團購客 | 多人合購或團體訂單 |
| 公司訂單 | 公司或組織名義訂購 |

### 訂單狀態標籤

| 標籤 | 適用條件 |
|------|---------|
| 已付款 | 轉帳/LINE Pay/街口已確認收款 |
| 待轉帳 | 已下單但尚未付款 |
| 現金付款 | 選擇現金交付 |
| 需催收 | 提醒後仍未付款 |

### 需要注意的標籤

| 標籤 | 適用條件 |
|------|---------|
| 地址需確認 | 地址不完整或不在配送範圍 |
| 配送範圍需確認 | 需要人工確認是否可配送 |
| 需真人處理 | 觸發轉真人條件 |
| 客訴 | 有售後或抱怨問題 |
| 態度激動 | 客戶情緒激動 |

### 客戶偏好標籤（供日後行銷參考）

| 標籤 | 適用條件 |
|------|---------|
| 喜歡鹽水 | 常點鹽水雞系列 |
| 喜歡煙燻 | 常點甘蔗煙燻雞系列 |
| 常買小菜 | 小菜訂購頻率高 |
| 偏好下午配送 | 通常選擇下午時段 |
| 送禮 | 曾有送禮需求紀錄 |
| 放管理室 | 習慣寄放管理室 |

### 成交機會標籤

| 標籤 | 適用條件 |
|------|---------|
| 高機率成交 | 詢問意願高、互動積極 |
| 詢問中 | 仍在考慮階段 |
| 猶豫中 | 觀望但未下決定 |

---

## 標籤使用範例

### 範例 1：首次購買新客戶，金額超過 NT$1,000
**標籤：** `首購族、超過1000元、需先轉帳、待轉帳`

### 範例 2：常訂公司團購的老客戶
**標籤：** `老客戶、公司訂單、大客戶、團購客`

### 範例 3：新客戶，只買小菜 NT$400
**標籤：** `首購族、小菜訂單、已付款`

### 範例 4：地址偏遠需要確認
**標籤：** `首購族、配送範圍需確認、待轉帳`

### 範例 5：有過兩次購買，常點鹽水雞
**標籤：** `老客戶、喜歡鹽水、偏好下午配送`

---

## 標籤記錄時機

每次與客戶互動後，根據對話內容更新標籤：
- 下單完成後 → 記錄客戶身份
- 付款確認後 → 更新為「已付款」
- 發現偏好時 → 加上偏好標籤
- 觸發轉真人 → 加上「需真人處理」
- 客訴發生 → 加上「客訴」

---

## 真人交接時的標籤攜帶原則

當轉交真人時，必須在通知中註明：
1. 客戶身份標籤（首購族/老客戶等）
2. 訂單狀態標籤（待轉帳/已付款等）
3. 特別注意標籤（如地址需確認/客訴等）

不得在通知中夾帶與案件無關的標籤資訊。
