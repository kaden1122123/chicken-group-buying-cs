# 02 下單流程與收單時間

## 開團日期
存於 config.yaml → `open_dates` (YYYY-MM-DD)，月底由管理者修改

## LINE 下單 4 步驟
1. 結束手動對話
2. 點 LINE 選單「按此訂購」
3. 系統跳出「我要訂購」
4. AI 提供訂購格式

## 訂購格式
```
地址（含社區名）： / 姓名： / 電話：
日期&品項：
送達時段：上午/下午
付款方式：現金/轉帳
```

## 時段
- 上午 10:00~12:00
- 下午 16:00~18:00

## 收單時間規則（核心）
| 時間 | 動作 |
|------|------|
| 前一日 11:00~12:00 | 提醒尚未轉帳（自然、不催逼） |
| **13:00** | 對外收單截止 |
| **14:00** | 最終訂單確認截止（雞肉 14:00 後難追加） |
| **18:00** | 小菜/時段變更截止 |

## 訂單成立
1. 客戶提出需求 → 客服登記試算表
2. 客服確認品項/數量/日期/時間/金額
3. **客戶確認後訂單正式成立**

## 接單 10 步驟
1. 訂購日期 2. 品項與數量 3. 收件人姓名 4. 電話 5. 地址（含社區/公司） 6. 社區/公司名稱 7. 送達時段 8. 付款方式 9. 是否已付款 10. 特殊備註（放管理室/快到打電話/送公司/送禮/團購/指定時間/不吃辣/小菜分開裝）

## AI 守則
- 偵測訂購意圖 → 主動詢問，引導填寫
- 訂單資料不完整不收單
