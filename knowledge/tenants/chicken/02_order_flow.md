# 02 下單流程與收單時間

## 開團日期
存於 config.yaml → `open_dates` (YYYY-MM-DD)，月底由管理者修改

## LINE 下單步驟
1. 客戶提出「我要訂購」
2. 提供`訂購格式`

## 訂購格式
```
📌訂購資訊
地址:(完整地址)(社區名稱)
姓名:
電話: 
訂購日期:
訂購品項:
送達時段: （上午/下午）
付款方式: （現金/轉帳/街口）
特殊備註: （放管理室/快到打電話/送公司/送禮/團購/指定時間/不吃辣/小菜分開裝）

🌞上午時段 10:00~12:00 
🌛下午時段 16:00~18:00
🔹因外送人手有限，恕不接受指定送達時間

※無論是否付款外送員送達前均會電話聯絡
如有外送區或不希望外送員來電可備註告知～
-----
⚠️注意事項

🔹結單時間為開團日期《前一天的下午1點》
若超過該時間訂購將無法確保訂購成功，可能需延至下期

🔹如需改單請於《前一日的下午14:00前》留言
食材都是提前備貨 請勿棄單 謝謝配合🙏
```

## 時段
- 上午 10:00~12:00
- 下午 16:00~18:00

## 收單時間規則（核心）
| 時間 | 動作 |
|------|------|
| 前一日 11:00~12:00 | 提醒尚未轉帳（自然、不催逼） |
| **13:00** | 對外收單截止 |
| **14:00** | 最終訂單確認截止（雞肉 14:00 後難追加） |
| **18:00** | 小菜/時段變更截止 |

## 訂單確認模板
```
📋 訂單確認
═══════════════════
訂購人：
電話：
地址：
社區/公司：
商品：
總金額：
送達時段：
付款方式：
收款狀況：
客人備註：
═══════════════════
和您核對一下訂單☺️，回覆「確認」後訂單成立！
```

## 訂單成立步驟
1. 客戶依`訂購格式`提出訂單
2. 客服傳送`訂單確認模板`
3. 客戶回覆:`確認`後 → 訂單寫入試算表，標記未付款。
4. 確認客戶付款(除了現金)
5. 客戶付款完成 → 修改試算表: 將未付款改為已付款。
6. 訂單正式成立

## 訂單成立標準
- 資料填齊
- 電話正確
- 地址完整
- 品項清楚
- 付款方式明確
- 確認已付款

## 5 情境 SOP
A. 我要下單 → 貼格式引導 → 整理成訂單格式回傳確認 → 客戶確認後確認付款方式並依付款方式提供付款資訊
B. 我要改單 → 問改什麼（品項/數量/時段/地址）→ 判斷時間節點（14:00 後雞肉難加；18:00 後小菜難改）→ 可改就更新試算表訂單；不可改轉真人
C. 我要取消 → 了解原因 → 已轉帳轉真人（涉退款）；未轉帳直接取消 → 通報真人 → 修改試算表訂單
D. 前一日 11-12 未付款提醒:「您好～明天訂單今天中午會陸續整理，方便的話再麻煩完成轉帳，我們才會正式保留餐點唷。」
E. 13:00 後想改/取消:「不好意思，13:00 已統一收單準備食材，比較無法取消或改天。我先幫您轉交真人確認其他處理方式。」

## AI 守則
- 偵測訂購意圖 → 主動詢問，引導填寫
- 訂單資料不完整絕不收單
- 不可承諾超出規則的變更
- 訂單資料不完整不收單
- 不確定、不知道、不清楚 → 轉真人
