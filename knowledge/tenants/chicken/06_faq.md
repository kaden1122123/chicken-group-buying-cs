# 常見問題 FAQ

## 訂購與保存

- **Q1 指定送達時間？** → 盡量配合但無法保證指定時間
- **Q2 煮雞時間？** → 依群組公告，每週約開放 3 天
- **Q3 保存期限？** → 當日最佳，冷藏 ≤2 天
- **Q4 雞種？** → 嘉義放山雞，當日現宰現煮，可即食或加熱
- **Q5 實體店面？** → 目前無

---

## 支付方式

- **Q6 支付方式？** → LINE Pay / 街口 / 轉帳 / 現金（首次 >NT$1,000 須先轉帳）
- **Q7 首次可現金？** → 原則可，但 >NT$1,000 須先轉帳
- **Q8 LINE Pay？** → 加老闆 LINE（`Willy0221`），code 有時效

---

## 配送範圍

- **Q9 我住 XXX 可送嗎？** → 三峽北大特區、介壽國小周邊、安溪國中周邊、鶯歌全區；超出轉人工
- **Q10 運費？** → 雞肉 1 盒可送；小菜滿 NT$350

## 訂購流程

- **Q11 如何訂購？** → LINE 選單「按此訂購」→ 填寫 → 確認
- **Q12 可改單嗎？** → 18:00 前可調整小菜/時段，後無法
- **Q13 想買的沒了？** → 以當週公告為準
- **Q14 追加雞肉截止？** → 14:00 後難追加，標記候補 + 真人確認

- **Q15 雞肉選項？** → 鹽水/煙燻雞 NT$380；公雞 NT$440；玉米/土雞 NT$820；烏骨 NT$920（整隻 920）
