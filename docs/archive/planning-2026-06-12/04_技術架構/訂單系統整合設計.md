# 訂單系統整合設計（試算表機制）

> 建立時間：2026-06-05
> 負責人：brtclaw（規劃）
> 狀態：初版，待 Hubert 審查

---

## 核心理念

**用戶在 LINE 與 AI 對話完成下單 → AI 自動寫入 Google 試算表 → Hubert 在試算表確認訂單。**

日後可擴充：Gmail 通知、LINE 群組通知等。

---

## 系統架構

```
用戶（LINE）
    │
    ▼
┌──────────────────────┐
│  AI 客服對話流程     │
│  （引導用戶填寫      │
│   訂購資訊）          │
└──────────┬───────────┘
           │
           ▼（訂單確認）
┌──────────────────────┐
│  AI 寫入試算表       │
│  （Google Sheets API）│
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Google 試算表       │
│  （訂單總表）         │
└──────────┬───────────┘
           │
           ▼
    Hubert 確認與處理
```

## AI 收集訂單流程

### Step 1：確認下單意圖

```
用戶：我要訂雞肉
    ↓
AI：確認商品
「好的！請問您想訂什麼商品與數量呢？」
    ↓
用戶：鹽水雞 x1、甘蔗煙燻雞 x1、黑胡椒毛豆 x2
    ↓
AI：確認品項
「好的，您想訂購：
- 鹽水雞（半隻）x1 — NT$380
- 甘蔗煙燻雞（半隻）x1 — NT$380
- 秘製黑胡椒毛豆 x2 — NT$140
小計：NT$900
符合免運資格（雞肉訂購 1 盒以上）✅」
```

### Step 2：收集配送資訊

```
AI：「請提供以下配送資訊：
1. 姓名：
2. 電話：
3. 地址：（完整地址，若有社區名稱請一併提供）
4. 配送日期：[]
5. 配送時段：上午（10-12）/ 下午（16-18）」
```

### Step 3：確認付款方式

```
AI：「付款方式請選擇：
A. 銀行轉帳（提供帳號）
B. 街口支付（提供 QR Code）
C. 現金（限老客戶或 NT$1000 以下新客戶）」
```

### Step 4：訂單摘要確認

```
AI：「請確認您的訂單：
📦 訂單摘要
品項：
- 鹽水雞 x1 — NT$380
- 甘蔗煙燻雞 x1 — NT$380
- 秘製黑胡椒毛豆 x2 — NT$140
📍 配送：2026/06/07 上午
📞 收件人：王小明 0912-345-678
🏠 地址：新北市三峽區...
💰 總計：NT$900（免運）
💳 付款：銀行轉帳

請回覆「確認」完成訂購。」
```

### Step 5：寫入試算表 + 回覆用戶

```
用戶：確認
    ↓
AI 背景寫入試算表
    ↓
AI 回覆：
「✅ 訂單已成功送出！
訂單編號：20260605-001
請於 24 小時內完成轉帳，轉帳後請回覆「已轉帳」並提供截圖，我們將儘快確認。」
```

## 試算表權限設定

| 角色 | 權限 | 說明 |
|------|------|------|
| Hubert（擁有者） | 檢視/編輯/分享 | 完整控制權 |
| AI（Service Account） | 編輯（僅新增資料） | 只能新增列，不能刪除或修改 |
| 用戶 | 無 | 無法直接存取 |

---

## AI 寫入試算表的觸發條件

| 條件 | 說明 |
|------|------|
| 用戶回覆「確認」 | 訂單正式成立，寫入試算表 |
| 用戶回覆「已轉帳」 | 更新付款狀態為「已付款」 |
| Hubert 確認收款 | 更新付款狀態為「已確認」 |
| Hubert 修改配送資訊 | 更新對應列 |
