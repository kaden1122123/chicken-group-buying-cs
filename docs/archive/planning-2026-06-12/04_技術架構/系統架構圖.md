## 模組說明

### 1. Cloudflare Worker（現有 ✅）

**功能：** 資安過濾層
- LINE Signature 驗證（使用 Worker 的 `LINE_CHANNEL_SECRET`）
- Rate Limiting（每分鐘 30 次、每日 500 次）
- Prompt/SQL Injection 偵測
- **付款關鍵字攔截**（短訊息 ≤50 字 + 付款關鍵字）
- 訊息轉發到 OpenClaw Gateway

**位置：** `external-user/cloudflare-worker/`

**轉發邏輯（2026-06-08 修復）：**
- Worker 修改 body（過濾 blocked events）後，必須為新 body 重新計算 signature
- 使用 `generateLINESignature(newBody, env.LINE_CHANNEL_SECRET)`
- 轉發時 header `X-Line-Signature` 使用新 signature（非原始 signature）

**轉發目標：** `https://openclaw.brt1122.com/line/534zsteg`

```
LINE → Worker(/webhook) → 驗證 signature ✅
                          ↓
                    過濾 blocked events
                    產生 newBody
                          ↓
                    為 newBody 產生 newSignature
                          ↓
                    POST /line/534zsteg
                    Header: X-Line-Signature: newSignature
                          ↓
                    OpenClaw 用 534zsteg 驗證 ✅
```

## dmpolicy 設計

### 政策選項

| 政策 | 說明 | 優點 | 缺點 |
|------|------|------|------|
| allowlist | 只允許特定用戶使用 | 安全可控 | 新用戶需審核 |
| open | 所有 LINE 用戶都可使用 | 開放易用 | 需做好 Rate Limiting |

**建議：** 初期先走 open，觀察使用情況再決定是否改為 allowlist

### 允許的操作範圍

| 操作 | 允許？ | 說明 |
|------|-------|------|
| 查詢商品資訊 | ✅ | 知識庫檢索 |
| 查詢價格優惠 | ✅ | 知識庫檢索 |
| 查詢運費 | ✅ | 知識庫檢索 |
| 引導下單 | ✅ | 但需用戶自己完成匯款等步驟 |
| 查詢訂單 | ❌ | MVP 不實作，未來需要身份驗證 |
| 修改/取消訂單 | ❌ | MVP 不實作 |
| 獲取 Hubert 個資 | ❌ | 絕對禁止 |
