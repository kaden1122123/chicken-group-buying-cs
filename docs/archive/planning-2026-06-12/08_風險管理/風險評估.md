# 風險評估

> 建立時間：2026-06-01
> 狀態：規劃階段

---

## 已識別風險

### R1：知識庫內容不準確

| 項目 | 內容 |
|------|------|
| 風險描述 | AI 回答錯誤的價格/商品資訊，導致用戶誤解 |
| 發生可能性 | 中（取決於 Hubert 提供的資料品質）|
| 影響程度 | 高（可能影響商譽和銷售）|
| 緩解措施 | 每次上線前由 Hubert 親自驗證知識庫內容 |
| 應變方式 | 發現錯誤立即更新知識庫，向用戶道歉並修正 |

---

### R2：知識庫內容過時

| 項目 | 內容 |
|------|------|
| 風險描述 | 商品價格/優惠內容已變更，但 AI 還在回答舊資訊 |
| 發生可能性 | 高（如果 Hubert 忘記更新知識庫）|
| 影響程度 | 中（用戶獲得過時資訊）|
| 緩解措施 | 建立知識庫更新流程，Hubert 變更時同步更新 |
| 應變方式 | AI 回覆時加入「以最新公告為準」等免责語 |

---

### R3：Human Handoff 機制失敗

| 項目 | 內容 |
|------|------|
| 風險描述 | AI 無法處理的問題沒有成功轉報给 Hubert |
| 發生可能性 | 低（機制單純）|
| 影響程度 | 高（用戶問題石沉大海）|
| 緩解措施 | 設計簡單明確的轉報流程 |
| 應變方式 | 每次轉報後 Hubert 主動確認是否有漏接 |

---

### R4：大量垃圾訊息/攻擊

| 項目 | 內容 |
|------|------|
| 風險描述 | 有心人士大量發送訊息，耗盡 Rate Limit 配額 |
| 發生可能性 | 中（取決於 Bot 曝光程度）|
| 影響程度 | 中（正常用戶可能受限）|
| 緩解措施 | Rate Limiting 機制（已部署）+ 監控異常流量 |
| 應變方式 | Cloudflare 封鎖來源 IP + 調整 Rate Limit 參數 |

---

### R5：Prompt Injection 攻擊

| 項目 | 內容 |
|------|------|
| 風險描述 | 用戶嘗試透過對話操控 AI 行為 |
| 發生可能性 | 高（常見攻擊手法）|
| 影響程度 | 中（取決於 Attack 的目標）|
| 緩解措施 | Cloudflare Worker 的 Prompt Injection 偵測（已部署）|
| 應變方式 | 阻擋惡意訊息並記錄攻擊者 |

---

### R6：LINE 官方政策變更

| 項目 | 內容 |
|------|------|
| 風險描述 | LINE 變更 Messaging API 政策，影響 Bot 功能 |
| 發生可能性 | 低 |
| 影響程度 | 高（可能需要緊急修改）|
| 緩解措施 | 關注 LINE Developers 公告 |
| 應變方式 | 根據 LINE 新政策調整實作 |
