## 功能詳細說明

### F1：團購商品諮詢

**描述：** 用戶詢問商品相關資訊（種類、規格、保存方式等），AI 能從知識庫中查找並回答。

**預期輸出：**
```
✅ 回覆商品種類與規格
✅ 回覆保存方式（冷藏/冷凍/室溫）
✅ 回覆最佳食用時機
```

**知識庫需要包含：**
- 商品列表（品名、規格、重量）
- 保存方式說明
- 烹飪建議（可選）

---

### F2：價格與優惠諮詢

**描述：** 用戶詢問價格、優惠活動、折扣碼使用方式。

**預期輸出：**
```
✅ 正確的價格資訊
✅ 當前優惠活動說明
✅ 折扣碼使用方式與限制
```

**知識庫需要包含：**
- 商品價格表
- 優惠活動內容與期間
- 折扣碼規則

---

### F3：運費說明

**描述：** 用戶詢問運費計算方式（分區、數量、滿額免運等）。

**預期輸出：**
```
✅ 運費計算規則說明
✅ 預估運費金額
✅ 滿額免運條件
```

**知識庫需要包含：**
- 運費計算規則（分區表）
- 滿額免運門檻
- 特殊地區說明

---

### F4：下單引導

**描述：** 引導用戶完成團購下單流程。

**預期輸出：**
```
✅ 告知下單方式（LINE直接下/填表/匯款）
✅ 提供必要的下單資訊（品項、數量、收件資訊）
✅ 確認訂單內容
```

**對話流程：** 見「03_產品設計/對話流程設計.md」

---

### F5-F7：訂單相關（會員資料庫）

**說明：** 這三個功能需要會員資料庫支援，屬於 P1 階段，MVP 先不實作。

**未來實作需要：**
- 會員資料庫（SQLite）
- 訂單資料庫
- 身份驗證機制

---

### F7：售後服務（退換貨、客訴）

**策略：統一文字回覆 + 人工處理**

**說明：** AI 收到退換貨、客訴相關問題時，用制式化短回覆安撫，再通知人工處理。不做復雜的對話判斷。

**預期輸出：**
```
✅ 制式化短回覆（已收到您的問題，將盡快與您聯繫）
✅ 通知 Hubert 有新客訴
```

**對話範例：**
> 用戶：商品有問題要退貨
> AI：感謝您的反映！我們已記錄，將盡快與您聯繫處理。🙇

**Hubert 通知機制：** AI 回覆後，自動發送通知到 Hubert（LINE/Email）

---

### F8：人員接管（Human Handoff）

**描述：** 當 AI 判斷無法處理當前任務時，自動轉接真人處理。

**觸發條件：**
1. AI 連續 3 次無法正確回答
2. 用戶明確要求「真人服務」「我要跟人說」
3. 偵測到特定關鍵字（客訴、退貨、退款、申訴）
4. 用戶明確表示不滿（情緒關鍵字）

**轉報方式：**
- 通知 Hubert 有新轉報（LINE/Email）
- AI 回覆：「已通知管理員，將盡快與您聯繫」
