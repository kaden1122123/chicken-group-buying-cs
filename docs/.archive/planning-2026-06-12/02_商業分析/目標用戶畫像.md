## 主要用戶群

### 用戶群 A：一般消費者
| 項目 | 內容 |
|------|------|
| 典型情境 | 想要買雞肉但懶得出門，直接 LINE 詢問 |
| 常見問題 | 「你們賣什麼？」「價格多少？」「可以冷藏配送嗎？」|
| 使用裝置 | 手機 LINE |
| 使用時間 | 晚上或假日居多 |

### 用戶群 B：團媽/團購主
| 項目 | 內容 |
|------|------|
| 典型情境 | 幫團員下單，需要大量資訊 |
| 常見問題 | 「團購價多少？」「最低訂量多少？」「運費怎麼算？」|
| 使用裝置 | 手機或電腦 |
| 使用頻率 | 高（長期合作）|

### 用戶群 C：餐廳/商家採購
| 項目 | 內容 |
|------|------|
| 典型情境 | 餐廳老闆詢問商用採購 |
| 常見問題 | 「有量的折扣嗎？」「可以定期配送嗎？」「有發票嗎？」|
| 使用裝置 | 手機或電腦 |
| 單次詢單量大 | 是 |
